# 古堡九夜 · 玩法系统设计案

> 项目代号 `castle-nine`。SillyTavern 内 AIRP 角色卡：代码负责确定性系统，LLM 负责叙事与角色。
> 本文只定系统与数值口径，不做实现。所有数值为首版基准，调参挂点集中标注。

---

## 0. 定位

一张「带真实系统的角色扮演卡」，不是纯文字冒险，也不是纯数值游戏。

- **代码负责**：房间刷新、道具抽取、时间推进、怪物行为、破门结算、升级校验、经济。
- **LLM 负责**：八名 NPC 的对话与好感、古堡的环境叙事、怪物逼近的感官描写、玩家自由行动的语义承接。
- **硬边界**：LLM 不写数值。玩家在面板上做的操作才算数；聊天里说「我把门加固」不会改变门的状态，除非走到面板施工。

一句话玩法：白天在每天重组的古堡里搜刮、施工、与人周旋；夜里守着门，或者赌命出门。

---

## 1. 世界与基调

古堡不在任何地图上。它每过一个白天就重新排列一次自己的房间，像一栋会消化的建筑。

九个人被困在里面：八张固定面孔，一个是你。每天 08:00 天亮，20:00 天黑，一天二十四小时被切成两半，一半用来准备，一半用来活下来。

天黑以后，没有理智的东西来敲门。它们不会谈判，不会疲倦，也记不住昨天撞坏的是哪块门板。

基调：**恐怖为底，黑色幽默为表**。恐惧来自规则本身（房间会变、门会坏、NPC 会消失、古堡会记住你），幽默来自人的反应（有人把保命道具当传家宝供着，有人给怪物起外号）。不写廉价惊吓，不写无意义的血腥。

## 2. 角色

完整角色方案见 `03-角色设计.md`。这里只列与系统耦合的规则。

### 2.1 角色与职业的关系

- **单人游戏**：玩家只有一个角色，自定义姓名、外观、四维与职业。
- **NPC 是服务网**：善良 4 名、中立 4 名，只在白天出现，用于交易、给道具、提供帮助。
- **没有职业分配**：八个预设角色与 8/9 人局全部删除；NPC 不占职业、不参与守门、不被怪物杀死。
- 完整 NPC 规则见 `04-NPC设计.md`。

### 2.2 九个职业

| 职业 | 定位 |
|---|---|
| 推演者 | 情报、预判、施工规划 |
| 修补匠 | 修理、改装、材料回收 |
| 守夜人 | 夜视、怪物意图预警 |
| 扛门人 | 扛门、减伤、正面阻挡 |
| 拆墙者 | 开路、制造捷径 |
| 嗅探者 | 搜物、追踪、找人 |
| 无梦者 | 恐惧抗性、替人承压 |
| 拾遗者 | 拾取、回溯、额外小时 |
| 守墓人 | 遗物、降低注视、与死者打交道 |

### 2.3 四维：只做判定

| 属性 | 只用于 |
|---|---|
| 体魄 | 扛门、搏斗、负重类判定 |
| 智识 | 施工、解读、机关判定 |
| 感知 | 搜索、夜行视野、察觉意图判定 |
| 意志 | 夜间行动、恐惧抵抗判定 |

```
判定 = 1d10 + floor(属性 / 2) + 职业加成 + 道具加成 - 恐惧惩罚
```

- 四维**不派生**体力上限、负重、背包格、恐惧上限；这些统一（体力 10、背包 12 格、恐惧 10），职业被动可增减。
- 施工不再锁门槛，改为智识判定；失败则浪费时间与材料。扛门同理，低体魄也能顶，只是顶不住。
- 数值差距是概率差，不是资格差。

### 2.4 属性预算

| 来源 | 总和 | 单项 |
|---|---|---|
| 玩家角色 | 24 | 1–20 |

- 四维总和固定 24，单项上限 20，开局校验。
- 职业不因数值而锁死，任何分配都能选任何职业。

### 2.5 机制卡

职业提供：被动、主动（每天或每夜一次）、弱点、专属道具、恐惧失控行为。不再有 NPC 职能与同住加成。

## 3. 时间与行动

### 3.1 昼夜

| 阶段 | 时段 | 长度 | 结构 |
|---|---|---|---|
| 白天 | 08:00–20:00 | 12 小时 | 12 个「时格」，行动按小时消耗 |
| 黑夜 | 20:00–次日 08:00 | 12 小时 | 6 个「更」，每更 2 小时 |

两个刷新节点：

- **08:00**：房间重组、搜索点重置、白天道具池生成、陈设槽重置。
- **20:00**：怪物入场、陈设槽异变判定、未搜索点按夜间权重重新生成。

### 3.2 白天行动（消耗时格）

| 行动 | 耗时 | 体力 | 说明 |
|---|---|---|---|
| 移动到相邻公共房间 | 1h | 1 | 走廊相连 |
| 搜索一个搜索点 | 1h | 1 | 触发道具或危险 |
| 返回自己房间 | 1h | 1 | 经大厅回房间 |
| 施工（升级部件/设施） | 1–3h | 1 | 智识判定，失败则浪费时间与材料 |
| 休息 | 2h | +3 | 白天休息不恢复恐惧 |
| 交谈/交易 | 1h | 0 | 与 NPC 互动，可换取情报、道具或材料 |
| 整理背包/搬运放置道具 | 1h | 1 | 玩家自带的放置道具可搬走；房间自带的不可搬走，只能就地使用/升级 |

白天时间耗尽或体力归零，强制回房休息至天黑；体力归零时不能进行夜间外出。

### 3.3 夜间行动（每更一次）

**门未破时：**

| 行动 | 效果 | 代价 |
|---|---|---|
| 守门 | 门部件受到伤害 -20% | 体力 -1 |
| 修理 | 修复一个部件 25 点，不超过该等级上限 | 体力 -2，需要材料 |
| 使用道具 | 按道具效果 | 按道具 |
| 睡眠 | 恢复体力 2，跳过本更；不恢复恐惧 | 无法反应，门无人守 |
| 外出 | 移动到相邻房间并搜索一次；遭遇怪物时消耗 4 体力或道具逃脱 | 体力 -2，房间无人，怪物伤害 +30% |
| 施工 | 临时加固（+40 临时耐久，天亮清零；每夜 1 次，消耗木料 ×1） | 体力 -2，有概率被打断 |

**门破后（入室阶段）：**

| 行动 | 效果 | 代价 |
|---|---|---|
| 用药 | 使用治疗、保命或控制道具 | 按道具 |
| 封门 | 木料 ×2，体魄判定对抗 8；成功赶出怪物，获得 30% 总耐久的临时护盾（天亮清零，不修复门本体）；失败受伤 2 | 每夜 1 次 |
| 逃跑 | 体力 -2，体魄判定对抗 8；破窗锤/绳索 +2，烟幕弹必成；钉墙者在场时难度 +2，且破窗锤/绳索失效 | 成功脱离房间，怪物留在原房；犬形会追 |
| 硬撑 | 不行动 | 本更承受全部入室伤害 |

### 3.4 体力与恐惧

- 体力上限统一 10，不随四维变化；职业弱点可增减。
- 体力 ≤ 3：搜索成功率 -20%，施工时间 +1h。
- 体力 = 0：昏睡至天亮，期间门无人守。
- **血量 HP**：初始 10，统一，不随四维变化；职业与道具可增减。HP 归零即死亡。
- **受伤判定**：每次受伤，体魄判定对抗 8，成功则伤害 -1（最低 1）。
- 白天休息 2h：HP +1（每个白天最多 +2）；床 3 级休息额外 +1，不计入每日 +2 上限。
- **08:00 天亮回复**：体力 +3、HP +1、恐惧 -2，均不超过各自上限/下限。
- 恐惧 0–10。夜里每更 +1（房内有灯 -0.5），怪物入室 +3，NPC 被吓跑 +2。
- 恐惧 ≥ 7：所有判定 -1；恐惧 = 10：失控一更（代码随机行动），失控结束后恐惧降到 8。

### 3.5 夜间外出遭遇

- 夜间每更外出时 roll 一次遭遇，概率 = 25% + 最高品阶仇恨 × 3%（仇恨值见 5.1）。
- 遭遇后先选择是否逃脱：
  - 消耗 4 点体力逃脱；体力不足 4 则无法选择。
  - 使用一次性或多次使用道具逃脱（破窗锤、绳索、无光粉、烟幕弹），不消耗体力。
- 不逃脱则按怪物类型结算：

| 遭遇怪物 | 后果 |
|---|---|
| 犬形 | 受伤 3 |
| 裂口者 | 受伤 5 |
| 第九位 | 受伤 6 |
| 守门犬 | 受伤 4 |
| 数息者 | 受伤 1，并继续倒数 |
| 缠足 | 体力 -2，移动失败 |
| 拾骨者 | 失去 1 件道具 |
| 守夜人 | 被赶回房间 |
| 破门型（仅夜间外出遭遇） | 受伤 1，被追回房间 |
| 欺骗型（无面客） | 被诱回房间，失去 1 件道具 |
| 封锁型（钉墙者） | 被钉在房间内，受伤 2，下一更无法外出 |
| 精神型 | 恐惧 +2 |

- 不逃脱的伤害结算后返回房间；HP 归零死亡。
- 入室阶段破门型不伤害玩家；表中「破门型受伤 1」只适用于夜间外出遭遇。
- 夜间在房间外体力归零也视为死亡。
- 遭遇不触发战斗；怪物没有血量，也不会被杀死或击退。

## 4. 古堡与房间

### 4.1 结构

古堡分三块：

- **玩家房间**：固定，独立，不参与任何刷新。
- **大厅**：固定，独立，不参与刷新；玩家房间直接连接大厅。
- **公共层**：12 个槽位排成 3×4 网格，其中一格固定为大厅，其余 11 格每天 08:00 从房间池重新抽取，不重复。

邻接关系固定：玩家房间 ↔ 大厅；大厅与网格中上下左右相邻的槽位相连；网格槽位之间上下左右相连。单人局没有住处走廊。

### 4.2 房间池（24 间）

R24 固定为大厅，不参与每日抽取；其余 23 间参与刷新，R23 每天必在。

### 4.3 每日刷新（代码）

```
seed = hash(局ID + 天数 + "rooms")
大厅固定为 R24，不参与抽取；玩家房间独立，不参与抽取
刷新槽位 = 11 个，从剩余 23 间按风险权重抽 11 间（不重复，R23 必在）
每间房品阶倾向 = 基础倾向 + 天数偏移（第 4 夜起高风险房间权重上升）
搜索点道具 = 按房间倾向 roll 品阶 → 按品阶 roll 道具
危险标记 = 基础危险 + 品阶加成，取较高值：品阶 ≥ 蜡 max(+1, 1)，品阶 ≥ 骨 max(+1, 2)
陈设槽 = 每房 1 个，白天为空，20:00 判定是否异变
```

- 同一槽位不连续两天出现同一房间；记录昨日槽位布局，替换时排除。
- 「第九间房」每天必在池中，但它的内容随机；进入后可能是空房、遗物房或通往异变的捷径。

### 4.4 危险

- 每个搜索点危险度 0–3。搜索时 roll 1d10，≤ 危险度 即触发。
- 危险表（按房间类型）：受伤（体力 -2）、恐惧 +2、引来夜行怪物（夜间该房怪物仇恨 +2）、损失时间（+1h）、道具损坏（刚搜到的道具降一阶）。
- 危险不是必死，是交易：高风险房间的蜡以上道具都伴随危险，玩家用体力、时间或恐惧去换。
- **稀有道具附近必有危险**：品阶 ≥ 蜡的搜索点，危险度取 max(基础+1, 1)；品阶 ≥ 骨，取 max(基础+1, 2)。
- 危险触发后道具仍留在搜索点，可再次搜索（再消耗 1h），该点危险度 +1。

### 4.5 夜间异变

- 20:00，每间公共房间的陈设槽 roll 一次。
- 概率 = 10% + 天数 × 3%（第 4 夜 22%，第 8 夜 34%）。
- 异变品阶：骨 55% / 瞳 35% / 无名 10%，天数越后越高。
- 异变物是「原本不是道具的东西」：一幅肖像的眼珠、一把椅子的脊椎、一扇门的牙。它不占搜索点，夜间进入该房即可免费取走，不额外判定。
- 异变物出现时，该房间危险度 +1，并可能触发一次怪物巡游。

## 5. 道具与品阶

### 5.1 品阶：六阶「古堡归档」

品阶不是稀有度标签，而是古堡对器物的分类方式。每一阶有明确的材质与来历判定，也各有机制副作用。

| 品阶 | 定义 | 判定标准 | 售价 | 夜间仇恨 | 特殊规则 |
|---|---|---|---|---|---|
| **尘** | 无主之物 | 拼凑、磨损、无使用痕迹残留 | 1 | 0 | 可在任何房间当杂物丢弃，不引怪 |
| **锈** | 用旧之物 | 金属/机械，有长期使用痕迹，不见主人 | 3 | 0 | 可拆解，必得 1 份材料 |
| **蜡** | 被保存之物 | 被刻意保养、包裹、藏起，残留前主人的习惯 | 8 | 1 | 携带 3 件以上，夜里每更多 10% 遭遇 |
| **骨** | 涉死之物 | 与死亡直接相关，含残念 | 20 | 2 | 夜里携带会吸引「拾骨者」 |
| **瞳** | 注视之物 | 有观看/被观看属性，改变持有者的感知 | 55 | 4 | 面板出现「被注视」提示，偶发幻象 |
| **无名** | 无法归档之物 | 无来源、无法描述、古堡拒绝记录 | 150 | 7 | 单件全局唯一；携带时怪物必定优先锁定 |

- 品阶严格向上，不可跨阶合成。
- 同名道具只存在于一个品阶。
- 无名阶道具每局最多 3 件，彼此不重复；抽取时硬性拦截，达到 3 件后不再生成无名。

### 5.2 提取权重

| 场景 | 尘 | 锈 | 蜡 | 骨 | 瞳 | 无名 |
|---|---|---|---|---|---|---|
| 白天 · 低风险房 | 55 | 30 | 13 | 2 | 0 | 0 |
| 白天 · 中风险房 | 35 | 30 | 20 | 12 | 3 | 0 |
| 白天 · 高风险房 | 15 | 20 | 25 | 22 | 15 | 3 |
| 夜间 · 低风险房 | 30 | 30 | 24 | 12 | 4 | 0 |
| 夜间 · 中风险房 | 18 | 24 | 25 | 20 | 11 | 2 |
| 夜间 · 高风险房 | 5 | 12 | 20 | 28 | 27 | 8 |

夜间整体系数上移，高风险房间的无名概率是白天的 2.7 倍。这是夜里出门的唯一理由。

### 5.3 四类道具

#### 放置道具（16 件，常驻房间，可升级，占用炉压）

| 道具 | 阶 | 炉压 | 效果 | 升级 |
|---|---|---|---|---|
| 守夜灯 | 锈 | 1 | 夜间视野 +1，房内被袭击概率 -10% | 2 级：范围覆盖走廊；3 级：怪物进入前预警 1 更 |
| 腌渍瓮 | 尘 | 1 | 在所在房间每天可收取 1 份食物（1h） | 2 级：2 份；3 级：1 份蜜饯 |

## 6. 升级系统

原作是「金币 → 等级 → 数值线性上涨」。本卡改成**四维约束**：材料、时间、智识、炉压，加上一个反向的压力源「古堡注视」。

### 6.1 玩家房间的四项基础

| 设施 | 作用 | 等级 |
|---|---|---|
| **门** | 阻挡怪物，由 4 个独立部件组成 | 每部件 3 级 |
| **床** | 恢复体力，决定睡眠风险 | 3 级，2 条互斥分支 |
| **灯** | 夜间视野与怪物命中 | 3 级，2 条互斥分支 |
| **炉** | 提供炉压，承载放置道具 | 3 级 |

### 6.2 门：部件化

门不是一条血条。怪物按攻击类型打不同部件，部件损坏会引发连锁。

| 部件 | 1 级耐久 | 2 级 | 3 级 | 抗性 | 损坏后果 |
|---|---|---|---|---|---|
| 门板 | 100 | 180 | 320 | 撞击 | 门整体伤害 +20% |
| 门轴 | 60 | 100 | 160 | 腐蚀 | 门无法闭合，怪物伤害 ×2 |
| 门闩 | 80 | 140 | 180 | 撬、模仿 | 无面客可直接开门 |
| 门框 | 120 | 200 | 240 | 啃咬 | 怪物可从墙缝进入 |

门总耐久 1 级 360，2 级 620，3 级 900。修理需要对应材料与时间，夜间修理消耗 2 体力。

### 6.5 炉：炉压

| 等级 | 炉压上限 | 成本 |
|---|---|---|
| 1 | 6 | 初始 |
| 2 | 10 | 35 铜扣、铁件 ×2、火油 ×2、2h |
| 3 | 16 | 90 铜扣、铁件 ×3、骨粉 ×1、3h |

- 所有放置道具占用炉压，超载则全部停摆 1 更，并触发「跳闸」事件（恐惧 +2）。
- 炉压就是玩家的"强度预算"：想在房间里堆设施，先升级炉子。

### 6.6 施工限制

- 只能在白天施工。夜间施工是临时加固：每夜 1 次，消耗木料 ×1，+40 耐久，天亮失效。
- 施工需要角色在房间内，且体力 ≥ 2。
- 施工不锁门槛，改为智识判定：难度按部件等级（1 级 6 / 2 级 8 / 3 级 10）。失败则浪费时间，材料损失一半。判定自然 10 必成功，最低成功率 10%。
- 施工时间可请失忆工匠协助压缩 -25%，每天一次。

### 6.7 古堡注视（反向压力）

```
注视值 = 升级总次数 × 2
       + 当前炉压占用
       + 携带最高品阶 × 3（尘 0 / 锈 1 / 蜡 2 / 骨 3 / 瞳 4 / 无名 5）
```

- 每晚 20:00 结算一次，记为当夜「注视」。
- 注视值上限 40，超过按 40 算。
- 怪物数 = 1 + floor(夜数 / 2) + floor(注视 / 20)。
- 每只怪物攻击力 = (12 + 夜数 × 4.5) × (1 + floor(注视 / 20) × 0.1)。
- 降低注视的方式：熄灭炉火一整晚（设施全部停摆）、丢弃高阶道具、完成「熄灯仪式」（仅高风险房间）、使用熄灯油。
- 设计意图：堆得越满，来的东西越强。玩家必须在「守得住」和「不惊动古堡」之间取舍，而不是一路升级到底。

## 7. 怪物

怪物没有台词，没有谈判，没有理智。它们只有行为表。

### 7.1 种类

| 怪物 | 类型 | 出现夜 | 对门系数 | 对玩家 | 行为 | 反制 |
|---|---|---|---|---|---|---|
| 叩门者 | 破门 | 1 | ×1.2（门板） | 0 | 只撞门板；门破后砸设施 | 门板等级、蜡泪屏风 |
| 剥墙兽 | 破门 | 2 | ×0.8（门框） | 0 | 绕门，从门框/墙缝进入 | 门框、墙体 |
| 无面客 | 欺骗 | 2 | ×0.6（门闩） | 0 | 模仿声音诱开门；门破后使你下一次判定 -1 | 门闩、蜡像替身 |
| 烛泪 | 破门 | 3 | ×1.0（门轴） | 0 | 腐蚀门轴，连锁破坏 | 门轴、镜面屏 |
| 裂口者 | 击杀 | 3 | ×0.6（门板） | 5/更 | 先撕门，门破后撕人 | 护心镜、急救包 |
| 饲影者 | 精神 | 4 | 0 | 0（恐惧 +2/更） | 门破后入室施加恐惧 | 明灯、无梦者 |
| 钉墙者 | 封锁 | 4 | ×0.7（门框） | 0 | 门破后钉死出口，逃跑难度 +2 | 撬棍、破窗锤 |
| 拾骨者 | 盗窃 | 4 | 0 | 0 | 偷骨阶以上道具；门破后偷背包 | 地窖桶、骨风铃 |
| 守夜人 | 占房 | 4 | 0 | 0 | 玩家离房时占房，返回需驱赶 | 骨哨、体魄判定 |
| 缠足 | 外勤 | 3 | 0 | 0 | 夜外拖慢，体力 -2 | 提灯、无光粉 |
| 数息者 | 外勤 | 5 | 0 | 1/更 | 夜外倒数，超时受伤 | 怀表、绳梯 |
| 守门犬 | 守门 | 5 | 0 | 4（返回一次） | 蹲守门口，玩家返回时咬一口 | 驱犬香、无光粉 |
| 犬形 | 击杀 | 5 | 0 | 3/更 | 追踪外出者；门破后咬人 | 绳索、破窗锤 |
| 低语者 | 精神 | 6 | 0 | 0（恐惧 +1/更） | 不入室，只加恐惧 | 镇静香、无梦者 |
| 第九位 | Boss | 3 / 6 / 9 | ×1.0 | 6/更 | 混合；记住上次防御方式 | 轮换防御 |

- 对门伤害 = 7.2 的攻击力 × 对门系数 × 部件抗性；对玩家伤害是固定值，不随夜数增长。
- 外勤型（缠足、数息者）、守门型（守门犬）、占房型（守夜人）不进入每夜主池，分别在夜间外出、返回、离房时触发；主池只抽破门/击杀/精神/盗窃/欺骗/封锁。
- 每夜从已解锁怪物中抽 N 只，不重复；N = 1 + floor(夜数 / 2) + floor(注视 / 20)。
- 第九位在第 3、6、9 夜固定加入，不占抽取名额。
- **破门型只打门，不能杀玩家；击杀型才能对玩家造成伤害。** 门破后若场上没有击杀型怪物，玩家不会持续掉血，但设施与道具会被破坏。

**特殊机制：**

- **数息者**：夜间外出时每更倒数 1，累计 3 次后受伤 3 并被迫返回房间；离开当前房间则重置。
- **守夜人**：玩家离房时占房。返回时可选择：给 1 件道具、用骨哨召唤 NPC、或体魄判定对抗 8；失败受伤 2，房间仍被占。
- **拾骨者**：每晚 30% 偷一件骨阶以上道具；门破后每更 50% 偷一件；地窖桶/保险箱保护。
- **无面客**：夜间在门外模仿你认识的人的声音。开门则入室，恐惧 +3、失 1 件道具；不开门则恐惧 +1/更。门闩 ≥2 时无法开门，只能骚扰。
- **剥墙兽**：只打门框；门框归零后从墙缝进入，不绕过门。

### 7.2 行为结算（代码）

**门未破时**，每更每只怪物 roll 一次意图：

```
1. 攻击门（权重 50%）→ 按攻击类型选部件 → 伤害 = 攻击力 × 对门系数 × 抗性系数
2. 破坏设施（权重 15%）→ 随机放置道具停摆 1 更
3. 潜伏（权重 20%）→ 本更无动作，下更伤害 +50%
4. 换目标（权重 10%）→ 转向相邻公共房间，破坏那里的陈设
5. 特殊行为（权重 5%）→ 按怪物种类
```

- 每只怪物每夜最多行动 6 次（每更一次）。
- 怪物攻击力 = (12 + 夜数 × 4.5) × (1 + floor(注视 / 20) × 0.1)；对门系数见 7.1。
- 潜伏的 +50% 只生效一次，不叠加。

**门破后**，进入入室阶段，每更按固定顺序结算：

1. 击杀型对玩家造成伤害（裂口者 5 / 犬形 3 / 第九位 6），每次伤害先做体魄判定，成功 -1。
2. 精神型施加恐惧（饲影者 +2 / 低语者 +1）。
3. 破门型破坏一件放置道具，停摆到天亮。
4. 盗窃型偷一件道具（拾骨者）；欺骗型使你下一次判定 -1（无面客）。
5. 封锁型钉死出口（钉墙者），逃跑难度 +2。
6. 占房型占据房间（守夜人），玩家无法休息与施工。
7. 玩家执行本更行动（用药 / 封门 / 逃跑 / 硬撑）。

外勤型（缠足、数息者）与守门型（守门犬）不进入入室阶段，只在外出时生效。

玩家每更可做一个行动：

- 使用道具（治疗、保命、驱赶）。
- 临时封门：木料 ×2，体魄判定对抗 8，成功把怪物赶出，获得 30% 总耐久（108 / 186 / 270）的临时护盾，天亮清零，不修复门本体；失败受伤 2。每夜 1 次。
- 逃跑：体力 -2，体魄判定对抗 8；破窗锤/绳索 +2，烟幕弹必成；钉墙者在场时难度 +2，且破窗锤/绳索失效。
- 硬撑：不行动，等天亮。

天亮后怪物离开；被打爆的部件保持 0 耐久，其余部件保持破门时的数值，玩家需要修理被打爆的部件才能重新关门。犬形会追到相邻房间，其他怪物留在原房破坏设施。

- 怪物不会被杀死，也没有耐久；放置道具只能延缓破门，不能消灭怪物。

### 7.3 NPC

- 不再有同住角色，也没有其他角色的生存判定。
- NPC 只在白天出现，20:00 离开，不参与守门、不被怪物杀死。
- NPC 分为善良与中立，提供治疗、赠予、交易、情报；好感 0–5。
- 详细规则见 `04-NPC设计.md`。
- 玩家死亡或胜利时，NPC 状态不结算。

## 8. 经济与平衡

### 8.1 货币

| 货币 | 来源 | 用途 |
|---|---|---|
| 铜扣 | 摆钟、出售道具、NPC 交易 | 常规升级、购买消耗品 |
| 夜露 | 雨漏瓮、夜间异变、高风险房间 | 3 级门部件（各 1）、特殊交易 |

- 交易：NPC 以铜扣计价，价格 = 品阶售价 × 1.5；好感 ≥4 再 -20%。NPC 铜扣视为无限。
- 材料固定价：木料 2、铁件 3、布料 2、蜡 5、骨粉 8、火油 3（铜扣）。
- 治疗品（急救包、缝合针、止痛药、血瓶、绷带）每天最多购买 2 件，避免用钱抵掉 HP 约束。

### 8.2 首夜基准

- 玩家初始：HP 10、铜扣 20、体力满、背包 1 件锈阶道具、房间四项设施 1 级。
- 基线按「注视 20、平均对门系数 1.0、工匠每天修门 20（上限 60）、守夜老人第一更免伤」估算。
- 第 1 夜：1 只叩门者（系数 1.2），攻击力 16.5，免伤后 6 更 41；门 1 380。
- 第 3 夜：2 只 + 第九位（共 3 只），攻击力 25.5，免伤后 191；门 2 680。
- 第 5 夜：3 只 + 注视溢出的 1 只（共 4 只），攻击力 37.95，免伤后 380；门 2 680。
- 第 8 夜：5 只 + 注视溢出的 1 只（共 6 只），攻击力 52.8，免伤后 792；门 3 960。
- 第 9 夜：5 只 + 注视溢出的 1 只 + 第九位（共 7 只），攻击力 57.75，免伤后 1011；门 3 960，守门后 809，余 151。
- 门 1 380：第 3 夜 191 余 189；第 5 夜 380 打穿。
- 门 2 680：第 5 夜 380 余 300；第 8 夜 792，守门 634，打穿。
- 门 3 960：第 8 夜 792，守门 634 余 326；第 9 夜 1011，守门 809 余 151。终局仍需封门/治疗/逃跑。
- 收入参考：每天出售 4–5 件道具（约 40 铜）+ 摆钟 12 + 当铺 5，9 天约 501 铜；门 2 + 门 3 全套 310 铜，够。

### 8.3 平衡公式

```
每更期望伤害 = 攻击力 × 对门系数 × 0.5 × 怪物数 × 抗性系数
攻击力 = (12 + 夜数 × 4.5) × (1 + floor(注视 / 20) × 0.1)
怪物数 = 1 + floor(夜数 / 2) + floor(注视 / 20)
门可承受总伤害 = Σ 部件耐久
守门后实际伤害 = 期望伤害 × (1 - 守门减伤)
```

- 玩家必须在「升级门」与「升级炉/设施」之间分配有限的时间与材料。
- 注视机制保证：把所有资源砸进房间，怪物也会同步变强，收益递减。
- 门破后击杀型每更伤害：犬形 3、裂口者 5、第九位 6；HP 10 对应可撑 3 / 2 / 1–2 更。

### 8.4 难度预设（开局可选）

| 难度 | 差异 |
|---|---|
| 借住 | 怪物伤害 -25%，注视结算值 ×0.5 |
| 常客 | 基准 |
| 归古堡所有 | 怪物伤害 +25%，注视每夜 +2，死亡后本局锁定，只能新开聊天 |

- 单人局不再有 8/9 人补偿；怪物数只由夜数与注视决定。
- 注视上限 40。

### 8.5 胜利条件

- 撑过第 9 夜，第 10 天 08:00 大门打开，存活者离开古堡。
- 或集齐 3 件无名阶道具，在任意白天提前开启大门。
- 玩家死亡即失败，进入死亡结算。

## 9. 变量契约（MVU Zod，同层方案）

沿用 YuriOpening 的同层形态：前端渲染在消息楼层内，状态存 MVU 的 `stat_data`，跟随楼层快照。

### 9.1 读写路径

```js
// 同层面板读取
await waitGlobalInitialized('Mvu')
const data = Mvu.getMvuData({ type: 'message', message_id: getCurrentMessageId() })

// 面板动作写入：纯函数算完，整块替换 $game
_.set(data, 'stat_data.$game', applyAction(_.get(data, 'stat_data.$game'), action))
await Mvu.replaceMvuData(data, { type: 'message', message_id: getCurrentMessageId() })
```

- 写入口只有 `game/actions` 一个，和 you-de-dian 的纪律一致。
- 写入后主动驱动一次重渲染；同时监听 `Mvu.events.VARIABLE_UPDATE_ENDED` 兜底刷新。
- 所有随机都带 seed，同一局同一天可复现。

### 9.2 命名空间隔离

| 命名空间 | 前缀 | AI 可见 | AI 可写 | 内容 |
|---|---|---|---|---|
| `$game` | `$` | 否 | 否 | 时间、房间、道具、怪物、门、日志，全部权威状态 |
| `$快照` | `$` | 否 | 否 | 面板写入前的 `$game` 副本，用于 LLM 误更新时回滚；不进投影 |
| `_状态` | `_` | 是 | 否 | 给 EJS 的结构化摘要：HP、门破、怪物类型、夜数 |
| `_投影` | `_` | 是 | 否 | 给叙事的纯文本摘要，约 120 字 |
| `叙事` | 无 | 是 | 是 | NPC 印象、气氛等小字段 |

- `$` 前缀约定为对 AI 不可见，游戏数值从根上不进入模型视野，模型也就无从改动。
- `_` 前缀约定为 AI 可见但不可更新，专门承载投影。
- `叙事` 是唯一允许 LLM 写的区域，写入后由 `VARIABLE_UPDATE_ENDED` 校验取值范围。
- 三条前缀约定来自社区实践，实现阶段需在目标 MVU 版本上用探针确认。

### 9.3 状态形状（压缩）

```ts
$game: {
  _版本: number,
  局: { 天数, 小时, 阶段, 更数, 难度, seed },
  玩家: { 姓名, 外观, 职业, 四维, HP, 体力, 恐惧, 铜扣, 夜露, 背包: { id, 数量, 耐久? }[], 装备: id|null, 位置 },
  门: { 耐久: [门板, 门轴, 门闩, 门框], 等级: [1..3 × 4] },
  设施: { 床: { 等级, 分支? }, 灯: { 等级, 分支? }, 炉: { 等级 } },
  放置: { id, 耐久? }[],
  公共层: { 槽位: { 房: id, 点: [道具id|null, 危险, 已搜][], 陈设: 道具id|null }[], 昨日: id[] },
  npc: { [npcId]: { 好感, 位置, 今日已交互, 是否出现 } },
  夜: { 怪物: { 种类, 类型, 攻击, 意图 }[], 注视, 门破: boolean },
  日志: string[]   // 最近 30 条，旧条目折叠进日报
}
```

- 道具与房间只存 id 和可变字段，静态数据查表，不把整张表塞进变量。
- 公共层 12 槽 × 3 搜索点 = 36 个三元组，背包通常不超过 12 件，单层目标 < 8 KB。

### 9.4 初始化与迁移

- `[InitVar]` 条目只放空壳与 `_版本`，完整初始状态由开局页写入 0 层。
- 每次加载检查 `$game._版本`，缺字段补默认值，结构变更写迁移函数。
- 旧聊天没有 `$game` 时，视为未初始化，停在开局页而不是崩溃。

### 9.5 同层交互约束

- 只有最新楼层渲染可操作面板；历史楼层只读，避免把操作写进旧快照。
- MVU 的变量自动清理会回收旧楼层变量，历史楼层面板读不到状态时降级为只读摘要，不报错。
- 删消息、重新生成会回滚到上一楼状态，正好对应「重开这一天」；分支聊天各自独立。

### 9.6 LLM 更新边界

- 卡内变量更新规则只允许 `叙事.*` 路径。
- `VARIABLE_UPDATE_ENDED` 兜底：把 `$game` 与 `_投影` 恢复为写入前的值，只保留 `叙事` 的变更。写入前把当前 `$game` 复制到 `$快照`，回滚后清空 `$快照`。
- 面板写入后向 `$game.日志` 追加一条系统条目，避免模型看到数值无理由变化而尝试「修正」。

## 10. LLM 与代码的边界

### 10.1 LLM 能做的

- 用八名占位角色的口吻说话（每人一句人设 + 能力坐标即可支撑）。
- 描写房间的感官细节、怪物的逼近、天亮的疲惫。
- 承接玩家在聊天里的自由行动描述，给出**叙事回应**，但不改变数值。
- 在面板动作完成后，把结果写成一段有情绪的楼层。

### 10.2 LLM 不能做的

- 不决定房间刷新、道具品阶、怪物行为、破门结果。
- 不修改金币、耐久、体力、恐惧。
- 不发明道具或房间（可以用叙事形容环境，但不能给玩家实际不存在的物品）。

### 10.3 投影协议

每次面板动作后，`projection.js` 重新生成一段纯文本摘要，写入 `stat_data._投影`：

```
第2天 14:00 · 白天 · 剩余6小时
铜扣20 夜露0 · 体力7/10 · 恐惧2/10
门：板180 轴60 闩140 框200 · 炉压4/10
公共层：长餐桌厅(低) 画廊(高) 书房(中) 洗衣房(低) …
存活：A B C E F G H
最近：搜索画廊获得蜡泪屏风；肖像眨眼，恐惧+2
```

卡内世界书条目用 `{{get_message_variable::stat_data._投影}}` 注入这段文本（宏名需在目标 ST 版本验证；YuriOpening 实际使用的是 `{{format_message_variable::stat_data}}`）。

LLM 只读投影写叙事，不回写任何数值。完整状态永远不进提示词，避免 token 膨胀与剧透。

### 10.4 EJS 提示词控制

世界书条目可以用 EJS 按当前状态切换规则，避免把所有分支都塞进常驻提示词。

```ejs
<% const s = getvar('stat_data._状态') %>
<% if (!s) { %>
（变量尚未初始化）
<% } else if (s.门破) { %>
门已破。本更入室结算：击杀型怪物对你造成伤害，破门型只破坏设施。
<% } else { %>
门未破。破门型怪物只攻击门，不会伤害你。
<% } %>
<% if (s.HP <= 3) { %>
你处于濒死状态，任何击杀型怪物的一击都可能致命。
<% } %>
```

- 只读 `_状态`，不写任何变量；`$game` 保持对 AI 不可见。
- `_状态` 由 `projection.js` 在每次写入后生成，字段：`HP`、`门破`、`怪物类型`、`夜数`。
- 按门状态、HP 区间、怪物类型、当前夜数切换规则文本。
- 依赖 ST-Prompt-Template；未安装时降级为常驻条目，所有规则常显（token 略多，但功能不丢）。
- 数值结算仍由代码完成，EJS 不参与掷骰与刷新。
- `getvar` 的具体作用域与 MVU 楼层变量的兼容性，实现阶段在目标运行时验证。
