# 古堡九夜 · 玩家角色与职业设计案

> 配套 `01-玩法系统设计.md`、`04-NPC设计.md`。
> 单人游戏：玩家只有一个自定义角色，九个职业任选其一。其余人全部是 NPC。

---

## 1. 设计目标

- **单人**：玩家创建自己的角色，不再从预设角色里挑选。
- **职业是玩法手牌**：九个职业任选其一，提供被动、主动、弱点、专属道具。
- **四维只做判定**：不派生体力、负重、恐惧上限，不设职业门槛。
- **NPC 不占职业**：善良与中立 NPC 只提供交易、道具与帮助，见 `04-NPC设计.md`。

---

## 2. 玩家角色

### 2.1 创建

| 项 | 规则 |
|---|---|
| 姓名 | 自由填写 |
| 外观 | 从 8 张立绘中选一张作为头像 |
| 四维 | 总和 24，单项 1–20，自由分配 |
| 职业 | 九选一，无门槛 |
| 专属道具 | 从该职业的专属道具或同阶道具中任选 |
| 开局资源 | 铜扣 20、夜露 0、房间四项设施 1 级 |

- 四维总和固定 24，防止全属性拉满。
- 职业不因数值而锁死；0 智识也能当推演者，只是判定难。
- 没有默认角色、没有职业分配、没有同住加成。

### 2.2 判定

```
判定 = 1d10 + floor(属性 / 2) + 职业加成 + 道具加成 - 恐惧惩罚
≥ 难度 即成功
```

难度：普通 6 / 困难 8 / 极难 10。恐惧 ≥ 7 时额外 -1。

| 属性 | 只用于 |
|---|---|
| 体魄 | 扛门、搏斗、负重类判定 |
| 智识 | 施工、解读、机关判定 |
| 感知 | 搜索、夜行视野、察觉意图判定 |
| 意志 | 夜间行动、恐惧抵抗判定 |

### 2.3 资源

| 资源 | 上限 | 恢复 |
|---|---|---|
| HP | 10 | 天亮 +1、休息 +1（每天最多 +2）、药品 |
| 体力 | 10 | 天亮 +3、休息 +3、食物 |
| 恐惧 | 10 | 天亮 -2、道具、NPC 安慰 |
| 铜扣 | 无 | 摆钟、出售、NPC 交易 |
| 夜露 | 无 | 雨漏瓮、异变、高风险房 |

## 3. 九个职业

职业卡只描述机制。所有职业对玩家开放，没有推荐角色、没有 NPC 职能。

### 3.1 推演者

> 站久了会喘，脑子里装着一整座古堡。

| 项 | 内容 |
|---|---|
| 被动 | 地图显示危险等级；施工判定 +1 |
| 主动 | 每天 1 次「推演」：预知下一更怪物攻击哪个门部件 |
| 弱点 | 体力上限 -2；恐惧 ≥5 时所有判定 -1 |
| 专属 | 自我修改的古堡草图（蜡） |
| 恐惧失控 | 用粉笔把名字写满墙壁 |

### 3.2 修补匠

> 手指抖，但能把任何东西修到能用。

| 项 | 内容 |
|---|---|
| 被动 | 施工时间 -25%；拆解道具必得额外一份同阶材料 |
| 主动 | 每天 1 次「改装」：把一件道具临时改成同阶另一件 |
| 弱点 | 无法使用重型武器；夜外逃脱体力 +1 |
| 专属 | 缺三件的工具箱（蜡） |
| 恐惧失控 | 反复拆装同一件东西 |

### 3.3 守夜人

> 夜里看得比谁都清，也比谁都怕。

| 项 | 内容 |
|---|---|
| 被动 | 夜行视野 +2；察觉怪物意图 +2 |
| 主动 | 每夜 1 次「标记」：指定一只怪物，看到它下一更行动 |
| 弱点 | 恐惧上限 -2；独自夜行恐惧 +2/更 |
| 专属 | 不灭提灯（蜡） |
| 恐惧失控 | 熄灯躲进角落，拒绝行动 |

### 3.4 扛门人

> 能扛着门板走三层楼，看不懂门板上的字。

| 项 | 内容 |
|---|---|
| 被动 | 门类部件耐久 +20%；扛门 +2；受伤 -1 |
| 主动 | 每夜 1 次「以身抵门」：本更门免伤，自己受 3 伤 |
| 弱点 | 文字道具不可用；施工 -2 |
| 专属 | 嵌肩门闩（锈） |
| 恐惧失控 | 用拳头砸门，引来怪物 |

### 3.5 拆墙者

> 拆墙像拆纸，也常把承重墙当纸拆。

| 项 | 内容 |
|---|---|
| 被动 | 破坏判定 +2；可从非门入口进入房间 |
| 主动 | 每天 1 次「破壁」：砸开一堵墙，创造新走廊 |
| 弱点 | 危险触发 +10%；每次破坏恐惧 +1 |
| 专属 | 卷刃消防斧（锈） |
| 恐惧失控 | 朝最近的墙猛砸 |

### 3.6 嗅探者

> 鼻子比脑子先到。

| 项 | 内容 |
|---|---|
| 被动 | 搜索 +2；搜索点显示品阶；闻出人或怪 |
| 主动 | 每天 1 次「追踪」：锁定一个目标，得知位置 |
| 弱点 | 文字道具不可用；夜外遭遇 +15% |
| 专属 | 牙哨（骨） |
| 恐惧失控 | 循着气味乱跑 |

### 3.7 无梦者

> 从没做过梦，怪物也进不去他的梦。

| 项 | 内容 |
|---|---|
| 被动 | 免疫梦魇；恐惧上限 8；睡眠不恢复恐惧 |
| 主动 | 每天 1 次「代受」：替一名角色承受一次恐惧冲击 |
| 弱点 | 不能用想象类道具；NPC 好感增长减半 |
| 专属 | 停摆的怀表（蜡） |
| 恐惧失控 | 不会失控，但会彻底沉默 |

### 3.8 拾遗者

> 揣着一只不属于这个年代的怀表。

| 项 | 内容 |
|---|---|
| 被动 | 搜索额外得 1 件尘阶杂物 |
| 主动 | 每天 1 次「回溯」：回到一小时前的位置 |
| 弱点 | 怀表每用 3 次降阶，降阶随机失物 |
| 专属 | 不属于这个年代的怀表（蜡） |
| 恐惧失控 | 反复看表，时间感错乱 |

### 3.9 守墓人

> 他挖过古堡的每一寸土，知道哪一具尸体还没烂透。

| 项 | 内容 |
|---|---|
| 被动 | 高危房显示旧住户埋藏点；拾遗物不触发恐惧 |
| 主动 | 每天 1 次「掘墓」：随机获得锈/蜡/骨道具，或降低注视 2 |
| 弱点 | 交易价格 +10%；恐惧上限 -1 |
| 专属 | 没有柄的铲子（骨） |
| 恐惧失控 | 开始替自己挖坑 |

## 4. NPC

- 善良 4 名：老医者、守夜老人、厨娘、失忆工匠。
- 中立 4 名：当铺老板、面具商人、占卜师、拾荒者。
- NPC 只在白天出现，20:00 离开，不参与职业、守门、生存判定。
- NPC 好感 0–5，影响价格与额外服务。
- 完整规则见 `04-NPC设计.md`。

---

## 5. 死亡与胜利

- 玩家 HP 归零：本局结束，进入死亡结算。
- 撑过第 9 夜或集齐 3 件无名：胜利，大门打开。
- NPC 不会死亡，也不会被怪物带走；他们只是每天换个地方做生意。

## 6. 与系统的接口

### 6.1 状态字段

```ts
$game.玩家: {
  姓名: string,
  外观: string,          // 立绘 id
  职业: 九个职业之一,
  四维: { 体, 智, 感, 意 },
  HP: number, 体力: number, 恐惧: number,
  主动: { 名称, 剩余次数 },
  位置: string,
}
$game.npc: {
  [npcId]: { 好感, 位置, 今日已交互 }
}
$game.结局: { 胜利: boolean, 原因: string | null } | null
```

### 6.2 判定接入

| 行动 | 属性 | 难度 |
|---|---|---|
| 搜索 | 感知 | 房间风险（低 6 / 中 8 / 高 10） |
| 施工 | 智识 | 部件等级（1 级 6 / 2 级 8 / 3 级 10） |
| 扛门 | 体魄 | 怪物强度 |
| 夜间行动 | 意志 | 6 / 8 / 10 |
| 察觉意图 | 感知 | 8 |

### 6.3 创建校验

```js
function validateAttrs(attrs) {
  const total = attrs.体 + attrs.智 + attrs.感 + attrs.意
  if (total !== 24) return `四维总和必须为 24，当前 ${total}`
  for (const [k, v] of Object.entries(attrs)) {
    if (v < 1 || v > 20) return `${k} 必须在 1–20 之间`
  }
  return null
}
```

职业不参与校验，任何角色可以选任何职业。
